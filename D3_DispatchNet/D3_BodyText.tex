\section{Database}

To save data between different we used a database saved as several CSV files.\\
It will be loaded at startup, containing at least the account of the network manager, with default information.
The data will be managed within the code and saved to the database only at the end of the program.

The database contains one file for each set of data:
\begin{itemize}
    \item authenticated users
    \item junctions
    \item lines
    \item platform
    \item station data
