creates the Pathfinding_class

Enforces mandatory information like requester and parameters of the search, initializes the sorting algorithm enum to its default value and computes the result lists

Parameters
requesterwhich Passenger or AnonymousUser initiated the request, used for ticket generation
fromWhere the search starts
toWhere the search ends
afterThe earliest accepted time for the first train in a path to depart, is optional (all values pass) but if no "before" argument is specified defaults to current time
beforeThe latest accepted time for the last train in a path to arrive, is optional (all values pass)
Exceptions
BadFieldRequester, from junction or to junction are null, despite being mandatory
BadReqRequester object is not an instance of Passenger or AnonymousUser
NoPathThe "from" Junction cannot reach the "to" Junction
BadSearchNo path respects both "after" and "before" argument
